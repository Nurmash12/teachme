# Teach Me

Teach Me — это учебный проект для создания карточек по конспекту. Пользователь
вводит название и текст конспекта, а приложение формирует вопросы и ответы с
цитатами из исходного текста. Карточки сохраняются вместе с конспектом и
отображаются на отдельной странице; ответ и цитату можно раскрыть по запросу.

## Установка и запуск

Выполняйте команды из корневой папки проекта `teachme`.

1. Создайте и активируйте виртуальное окружение:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

2. Установите зависимости:

   ```powershell
   pip install -r requirements.txt
   ```

3. Примените миграции базы данных:

   ```powershell
   python manage.py migrate
   ```

4. Запустите сервер разработки:

   ```powershell
   python manage.py runserver 127.0.0.1:8000
   ```

5. Откройте <http://127.0.0.1:8000/> в браузере.

## Переменные окружения

Скопируйте `.env.example` в `.env` в корне проекта:

```powershell
Copy-Item .env.example .env
```

Доступные настройки:

- `TEACHME_MODE=demo` — локальный DEMO-режим, не требующий API-ключа.
- `TEACHME_MODE=live` — в текущей реализации не поддерживается. Для генерации
  через Gemini укажите `TEACHME_MODE=gemini`.
- `GEMINI_API_KEY` — API-ключ Gemini; необходим для режима `gemini`.

Например, для генерации через Gemini задайте в `.env`:

```dotenv
TEACHME_MODE=gemini
GEMINI_API_KEY=your-gemini-api-key
```

Не добавляйте настоящий API-ключ в репозиторий. Файл `.env` исключён из Git.

## Проверки

Из корневой папки проекта выполните:

```powershell
python manage.py check
python manage.py test study
python manage.py makemigrations --check --dry-run
```

## Ограничения

- В приложении нет аутентификации и владельцев конспектов: сохранённые записи
  не привязаны к конкретному пользователю.
- Проверка цитат подтверждает, что цитата точно совпадает с предложением в
  конспекте. Она не проверяет достоверность ответа и то, подтверждает ли цитата
  ответ по смыслу.
- DEMO-режим предназначен для локальной демонстрации; для генерации карточек по
  произвольным конспектам в текущей версии используйте поддерживаемый режим
  `gemini` и задайте `GEMINI_API_KEY`.
