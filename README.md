# Teach Me

Teach Me — учебное веб-приложение на Django для создания карточек по конспекту.
Пользователь отправляет название и текст конспекта, приложение генерирует
вопросы, ответы и цитаты, после чего сохраняет конспект вместе с карточками.

## Возможности

- Генерация карточек в DEMO-режиме или через Gemini.
- Проверка того, что каждая цитата карточки содержится в конспекте.
- Просмотр конспекта и карточек; ответы и цитаты скрыты до раскрытия карточки.
- Редактирование вопроса, ответа и цитаты с повторной проверкой цитаты.
- Удаление карточки с подтверждением.
- Отметка карточки как проверенной и сброс этой отметки после редактирования.
- Фильтры карточек: все, требующие проверки, проверенные; счётчики показывают
  общее состояние карточек конспекта независимо от выбранного фильтра.

## Установка и запуск

Все команды выполняйте из корневой папки проекта `teachme`.

1. Создайте и активируйте виртуальное окружение:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

2. Установите зависимости:

   ```powershell
   pip install -r requirements.txt
   ```

3. Примените миграции:

   ```powershell
   python manage.py migrate
   ```

4. Запустите сервер разработки:

   ```powershell
   python manage.py runserver 127.0.0.1:8000
   ```

5. Откройте <http://127.0.0.1:8000/>.

## Переменные окружения

Создайте локальный `.env` на основе шаблона:

```powershell
Copy-Item .env.example .env
```

Для локальной демонстрации дополнительных настроек не требуется:

```dotenv
TEACHME_MODE=demo
GEMINI_API_KEY=
```

Для генерации через Gemini задайте:

```dotenv
TEACHME_MODE=gemini
GEMINI_API_KEY=your-gemini-api-key
```

`TEACHME_MODE=live` не является поддерживаемым режимом. Не сохраняйте настоящий
API-ключ в репозитории: `.env` исключён из Git.

## Проверки

Запустить все тесты приложения и проверить конфигурацию:

```powershell
python manage.py check
python manage.py test study
python manage.py makemigrations --check --dry-run
```

Тесты функций редактирования, удаления, проверки и фильтрации можно запустить
отдельно:

```powershell
python manage.py test study.test_editor
```

## Ограничения

- В приложении нет аутентификации и владельцев конспектов; данные не привязаны
  к конкретному пользователю.
- Проверка цитаты подтверждает её наличие в тексте конспекта, но не оценивает
  смысловую связь цитаты с ответом и достоверность самого ответа.
- DEMO-режим предназначен для демонстрации. Генерация карточек для произвольных
  конспектов через Gemini требует действительного `GEMINI_API_KEY`.
